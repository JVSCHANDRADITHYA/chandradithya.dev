01 — Overview

See exactly what
you're buying

Ring Studio replaces static product photography with a live, interactive 3D configurator. Customers rotate a photorealistic ring model, swap metals, and change gem types — all inside a WebGL canvas rendered directly in the browser.

Metal swaps happen client-side with zero network overhead. Stone changes trigger a single debounced REST call to WooCommerce, returning the exact price and stock status for that configuration — no page reloads, no laggy spinners.

The headless architecture decouples the React storefront from WordPress rendering entirely, while preserving WooCommerce's mature order, payment, and fulfilment workflows under the hood.

02 — Architecture

Three-layer
data flow

Layer 01
Interactive 3D
Frontend UI
Built with Three.js / React Three Fiber. Renders GLTF ring models in a WebGL canvas with full orbit controls. Metal swaps — yellow, white, rose gold, platinum — and stone changes happen client-side with zero network overhead. A debounced REST call then syncs pricing.
Layer 02
REST API
Communication
Serialises every user selection into a structured JSON payload and dispatches it to WooCommerce asynchronously. Debouncing prevents request floods; optimistic UI updates keep the interface snappy even on slow connections.
Layer 03
Headless
WooCommerce
Single source of truth for products, variations, live pricing, and stock levels. The headless pattern decouples the React storefront from WordPress rendering, retaining WooCommerce's mature order, payment, and fulfilment workflows entirely intact.

05 — Getting Started

Up and running
in four steps

Step 01
Clone the repo
Pull the source from GitHub and enter the project directory.
Step 02
Configure environment
Copy the .env.example and set your WooCommerce URL, consumer key, and secret.
Step 03
Start dev server
Run npm install and npm run dev inside the urumi-ring directory.
Step 04
Open in browser
Navigate to localhost:5173 — the configurator is live.
# Clone
git clone https://github.com/JVSCHANDRADITHYA/ring-studio.git
cd ring-studio

# Environment
cp urumi-ring/.env.example urumi-ring/.env
# → Set WOOCOMMERCE_URL, WC_CONSUMER_KEY, WC_CONSUMER_SECRET

# Launch
cd urumi-ring && npm run dev
# → http://localhost:5173
06 — How It Works

Six-step
interaction flow

1
User opens the configurator — Three.js loads the GLTF ring model and renders it in a WebGL canvas.
2
User picks a metal — React state swaps the mesh material client-side. Zero network call. Instant.
3
User picks a stone — Instant local swap, then a debounced REST call fires to WooCommerce.
4
WooCommerce responds — Returns variation price and stock status for that exact combination.
5
UI updates — Price badge animates to the new value; out-of-stock options grey out automatically.
6
User clicks Add to Cart — WooCommerce cart endpoint is called; standard checkout follows.
